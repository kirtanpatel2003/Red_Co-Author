================================================================
Red_Co-Author — Incremental Development Checklist (7 Versions)
================================================================
Goal: Build the CoJP jailbreak pipeline + Laminar observability +
Streamlit dashboard + multi-target sweep + corpus/batch runner +
monitor with generalization eval, in seven working versions. Each
version must run end-to-end before moving to the next. No version
skips the previous one's tests.
